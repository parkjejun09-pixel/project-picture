# V0.6.6 Ruler & Assist Design

## Goal
Add a real assist/ruler subsystem that constrains drawing coordinates without baking guides into artwork. The subsystem must support grid, guides, straight, parallel, curve, radial, concentric, symmetry, and 1/2/3-point perspective workflows, with an always-visible Snap command state and contextual properties.

## Product behavior
- Assist overlays render above the artwork and are never exported.
- Pointer flow is `raw pointer -> assist snap/replication -> stabilizer -> brush/vector sampling` so the resulting stroke data is genuinely constrained.
- Standard mode exposes Grid, Guide, Straight and Snap. Advanced mode exposes Parallel, Curve, Radial, Concentric, Symmetry and Perspective detail controls.
- The user can toggle snapping globally from the command bar without deleting configured rulers.
- Symmetry can use 2–12 axes and clones brush coordinates around a movable center.
- Perspective supports 1-, 2-, and 3-point configurations using editable horizon/vanishing points.

## Architecture
Create pure geometry modules under `src/drawing/assist.ts` and `src/drawing/perspective.ts`. They have no DOM or canvas dependencies and are fully unit-tested. Editor state stores assist configuration, while `DrawingCanvas` owns pointer-to-canvas conversion and calls the pure assist functions before stabilizing/painting. A dedicated `AssistPanel` provides contextual controls, while `CommandBar` owns the global Snap toggle.

## Data model
`AssistMode`: `none | grid | guide | straight | parallel | curve | radial | concentric | symmetry | perspective`.

`EditorState` gains:
- `assistMode`
- `assistSnapEnabled`
- `gridSize`
- `guideOrientation`
- `guidePosition`
- `straightAngle`
- `parallelAngle`
- `radialCenterX/Y`
- `radialRays`
- `concentricSpacing`
- `symmetryAxes`
- `symmetryCenterX/Y`
- `perspectiveMode` (`one | two | three`)
- `perspectiveHorizonY`
- `perspectiveVanishingPoints`

Coordinates for ruler centers/guide positions are normalized 0..1 so they survive different canvas sizes.

## Snap rules
- Grid: nearest grid intersection.
- Guide: project to one horizontal or vertical guide.
- Straight: project the current point onto an infinite line through the stroke origin at configured angle.
- Parallel: same projection, but the line passes through the stroke origin and follows the configured reference angle.
- Curve: nearest sampled point on a cubic Bezier ruler.
- Radial: project from center onto the nearest ray based on configured ray count.
- Concentric: project to the nearest circle centered on the ruler center using configured spacing.
- Perspective: choose the vanishing point whose ray from stroke origin is closest to the raw pointer direction, then project to that ray.
- Symmetry: the primary point is not snapped; instead it generates N rotated copies. This must happen after primary snapping but before drawing.

## Overlay
`DrawingCanvas` renders overlays after document compositing and selection overlays. Grid/guides use low-contrast thin lines, active ruler geometry uses the existing muted blue accent, and draggable vanishing points/centers use small handles. Overlay rendering is view-only and never included in export composites.

## UI
- `ToolBar`: add an `Assist` tool.
- `CommandBar`: replace the placeholder Snap with a real stateful button.
- `AssistPanel`: selector for ruler type and controls for the selected assist mode.
- `PropertiesPanel`: when Assist is active, it surfaces the same assist state compactly.
- Keyboard: `R` selects Assist; snap toggle remains click-first for now to avoid stealing common shortcuts.

## V0.9 persistence strategy update
V0.9 changes from IndexedDB-first project storage to a hybrid strategy:
- On supporting browsers (Chrome/Edge-class support), use File System Access API for explicit `Open`, `Save`, and `Save As` of app-owned project files.
- Keep IndexedDB for autosave snapshots, crash recovery, and fallback where File System Access API is unavailable.
- Feature-detect the API and retain upload/download project-file fallback.
- File handles are never assumed to remain permitted forever; permission failures fall back to `Save As`.

## Testing
- Unit tests for every pure projection/symmetry/perspective function.
- Reducer tests for new editor state and clamping.
- Markup tests for real Snap and Assist controls.
- DrawingCanvas integration-source tests ensure snapping occurs before stabilizer and symmetry replication reaches brush drawing.
- Existing 140 tests must remain green.

## Non-goals for V0.6.6
- Editable spline ruler nodes beyond a single cubic curve preset.
- Arbitrary perspective plane grids or 3D scene rulers.
- Persisting rulers into project files before V0.9 format work.
