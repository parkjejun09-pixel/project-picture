# Drawing Studio V0.6.1 UI Reconstruction Design

## Goal
Replace the V0.6 dashboard/card-like workspace shell with a dense professional drawing workspace inspired by the information architecture of Clip Studio Paint and MediBang, while preserving Drawing Studio's existing engines and left/right-handed mirroring.

## Product principles
- Professional, not sparse: Standard mode must expose the common drawing workflow without forcing users into Advanced mode.
- Hierarchy over emptiness: frequent controls remain visible; deep settings live in tabs/disclosures.
- Docked palettes, not SaaS cards: panels visually connect into left/right dock columns and use headers, tabs, separators, and compact controls.
- Neutral depth: chrome, docks, panel headers, content, selected rows, and inputs use distinct charcoal values.
- Preserve app identity: use the structural lessons from Clip Studio/MediBang without copying their proprietary icons, logos, or exact assets.
- Existing brush, color, layer, fill, vector, selection, transform, history, preferences, and canvas engines remain intact.

## Workspace layout
1. Application menu bar: File, Edit, Layer, Select, Filter, View, Window, Help.
2. Command bar: undo/redo, save/export, transform access, snap placeholder state, brush size, opacity, stabilizer, zoom.
3. Document tab bar below command bar.
4. Main body has three regions:
   - tool strip + primary dock,
   - canvas workspace,
   - secondary dock.
5. Default right-handed layout:
   - far-left tool strip,
   - left dock: Color / Color Set, Sub Tool, Tool Property,
   - canvas,
   - right dock: Navigator, Layer Property / context properties, Layers, History/Workspace tabs.
6. Left-handed layout mirrors the two dock groups and tool strip around the canvas without mirroring artwork.

## Standard vs Advanced
Standard shows Color, Color Set, Sub Tool, Tool Property, Layers, Navigator, and contextual Properties.
Advanced additionally exposes Brush Studio, detailed Color Lab controls, History, Workspace settings, and deeper fill/vector controls.

## Visual system
- Border radius: 0–4px for docks/panels/inputs; 6px reserved for popovers or large interactive swatches.
- No detached rounded cards in permanent docks.
- Charcoal levels: app chrome darkest, dock background next, panel body slightly lighter, selected rows/active controls lighter again.
- Fine 1px separators between palette sections.
- Palette headers are 22–26px high and visually distinct from content.
- Text is compact: 10–12px common UI; section titles 10–11px.
- Selected/active accent is desaturated blue-gray, not bright purple.

## Color system UI
- Large circular hue ring with inset saturation/value field remains immediately visible.
- Foreground/background color chips sit adjacent.
- HEX visible by default.
- RGB/HSV, Harmony, Tone/Variants, image extraction move into tabbed/detailed Color Lab sections.
- Color Set is a separate always-visible palette grid in Standard mode.

## Panels
- Left dock: Color, Color Set, Sub Tool, Tool Property. Sub Tool content changes with active tool where practical.
- Right dock: Navigator, Properties/Layer Property, Layers, bottom tab stack (History / Workspace in Advanced).
- Brush Studio remains Advanced and appears as a tab/palette rather than a full card.
- Panels may collapse, but collapsing preserves a visible header/tab.

## Handedness
Right-handed default keeps tool strip/primary dock left and secondary dock right. Left-handed mode swaps primary/secondary dock groups and moves tool strip to the right edge. Canvas transforms and document coordinates are unchanged.

## Non-goals for V0.6.1
- No arbitrary drag-and-drop docking.
- No detached floating windows.
- No new drawing engine features beyond wiring existing features into the revised shell.
- No exact visual clone of Clip Studio or MediBang.
