# Drawing Studio V0.5 Workspace Design

## Goal
Turn the V0.4 engine-heavy editor into a professional, approachable workspace inspired by the density and organization of Clip Studio Paint and MediBang without copying either product's visual assets or layouts.

## Product principles
- Standard is a clean professional workspace, not a beginner-only mode.
- Advanced reveals deeper controls without replacing the user's learned layout.
- The canvas stays visually dominant, but surrounding UI should feel intentionally populated rather than empty.
- The workspace can mirror for right- and left-handed users.
- Existing Brush, Layer, Color Lab, and Smart Fill behavior remains intact.
- Panels are compact, collapsible, and stateful.

## Workspace shell
V0.5 adds a document tab row between the top command bar and editor body. The main editor body contains a compact tool rail, canvas stage, and inspector dock. Right-handed mode uses tools on the left and inspector on the right. Left-handed mode mirrors both positions.

The top bar exposes File-like actions, Undo/Redo, Standard/Advanced, a handedness toggle, and a Workspace button. A compact document tab gives the app a desktop-creative-tool visual hierarchy.

## Panel system
The inspector dock contains contextual panels. Standard mode shows Sub Tool/Tool Property, Color Lab, and Layers. Advanced mode additionally exposes Brush Studio, Navigator, History, and Workspace Settings. Every major panel has a collapse control. Collapse state is saved locally.

## Handedness
`right` is the default. In right-handed layout, the tool rail is left and the inspector dock is right. `left` mirrors them. The setting is available in Workspace Settings and through a small top-bar quick toggle. It is persisted to localStorage.

## Navigator
Navigator displays a live scaled copy of the composited canvas. It shows zoom and offers Fit and 100% actions. It is advanced-only so Standard stays approachable.

## History
History presents recent high-level editor operations and allows direct Undo/Redo through existing history. V0.5 does not implement arbitrary jump-to-history snapshots; it provides an honest operation log around the existing stack.

## Brush Studio
The current V0.2 pressure controls remain, but Advanced receives a dedicated Brush Studio panel with a larger pressure curve, preset metadata, and dynamic controls. Standard keeps the compact Sub Tool panel.

## Workspace settings
Controls include handedness, canvas surround (`neutral`, `dark`, `light`), UI density (`comfortable`, `compact`), shortcut profile (`Drawing Studio`, `Adobe-like`, `Clip-like`), and Reset Workspace. The profile currently changes displayed shortcut hints and core tool hotkeys where non-conflicting.

## Visual language
Use near-black neutral charcoal rather than blue/purple dark UI. Borders are fine and low-contrast, selected states use a muted steel-blue accent, corners are mostly 2-4 px, typography is compact, and the canvas surround is user-selectable. Avoid large empty cards and oversized rounded controls.

## Persistence
Workspace-only preferences live under a versioned localStorage key. Artwork data is not persisted in V0.5.

## Non-goals
- Free drag-and-drop docking between arbitrary zones.
- Multiple detached windows.
- Cloud workspace sync.
- Full shortcut editor UI.
- Arbitrary history time travel.
