# Drawing Studio V0.6.4 Brush Complete Implementation Plan

**Goal:** Expand the raster brush engine from pressure/tilt basics into a customizable painting system with richer dynamics, blending tools, and preset management.

**Architecture:** Keep brush configuration in editor state, deterministic dab math in focused drawing modules, canvas pixel operations in dedicated smudge/blur/mix modules, and UI in Brush Studio/Brush palette components. Preserve existing document/layer/vector APIs.

**Tech Stack:** TypeScript, Canvas 2D, Node test runner, existing no-dependency build pipeline.

## Tasks
1. Add failing tests for advanced brush dynamics: flow, velocity, rotation, taper, scatter, size/angle jitter, color jitter, texture/grain masks.
2. Implement deterministic advanced brush dynamics and extend presets/editor state/reducer.
3. Add failing tests for smudge, blur, and wet-mix pixel operations; implement image-buffer algorithms.
4. Add brush preset library/search/favorites/custom preset serialization model and tests.
5. Expand Brush Studio + brush palette UI and wire state/actions.
6. Integrate brush rendering and blend tools into DrawingCanvas.
7. Update feature matrix, roadmap, README, version metadata.
8. Run full tests/build and package tablet preview + ZIP.
