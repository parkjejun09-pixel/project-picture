# V0.6.6 Ruler & Assist Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add real drawing assists/rulers and snapping, plus update the V0.9 persistence roadmap to a File System Access API + IndexedDB hybrid.

**Architecture:** Pure assist geometry lives in focused drawing modules and is consumed by editor state, DrawingCanvas, and a dedicated AssistPanel. Overlays are visual-only; snapped coordinates feed the existing stroke engine before stabilization. The command bar owns a global Snap toggle.

**Tech Stack:** TypeScript, Canvas 2D, existing custom component system, Node test runner, no new runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-09-17-v0.6.6-ruler-assist-design.md`

## Global Constraints
- No new runtime dependency.
- Preserve existing V0.6.5 drawing, layer, brush, selection, transform, vector, and export behavior.
- Assist overlays must never be included in exported artwork.
- All new geometry must be testable without DOM/Canvas.
- Existing 140 tests must remain green.
