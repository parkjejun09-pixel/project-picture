# V0.4 Color Lab & Smart Fill Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an integrated professional color workflow and clean flat-color fill workflow to Drawing Studio.

**Architecture:** Add pure color-model and fill-algorithm modules under `src/drawing`, keep DOM rendering in focused panel components, and expose only editor state needed by the canvas. Smart Fill operates on ImageData/reference composites and writes only to the currently active raster layer. Color Lab remains workspace-local and updates the existing editor foreground color.

**Tech Stack:** TypeScript, Canvas 2D, DOM APIs, Node built-in test runner.

**Spec:** `docs/product/ROADMAP.md` V0.4 section.

## Global Constraints

- Keep V0.1-V0.3 drawing, brush, layer, mask, clipping and undo/redo behavior intact.
- No new runtime dependencies.
- Standard mode exposes core color and fill controls; Advanced mode exposes deeper palette/fill settings.
- Color calculations are deterministic and testable without a browser.
- Smart Fill must write to the active raster content target and participate in document history.
