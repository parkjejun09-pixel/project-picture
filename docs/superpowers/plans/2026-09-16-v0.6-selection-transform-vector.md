# Drawing Studio V0.6 Implementation Plan

**Goal:** Soften the V0.5 workspace into a layered Clip Studio/MediBang-inspired UI, then add functional raster selection/transform tools and first-class vector layers/strokes.

**Architecture:** Keep the V0.4/V0.5 drawing engines intact. Add pure selection/transform/vector geometry modules, a contextual Properties panel, and extend DrawingCanvas/layer state only at well-defined interfaces. UI styling uses multiple neutral charcoal surfaces and progressive disclosure rather than one flat black surface.

**Tech Stack:** TypeScript, Canvas 2D, DOM/CSS, Node test runner.

## Global Constraints
- Standard mode keeps primary drawing functions visible; Advanced exposes detailed controls.
- Right/left-handed mirroring must continue to work.
- No fake controls: visible V0.6 controls must perform an action.
- Existing V0.1–V0.5 tests must remain green.

### Task 1: UI Softening (V0.5.1)
- Add layered surface tokens and section depth to toolbar, document bar, inspector rail, and panels.
- Increase radius selectively on cards/interactive controls without making the app bubbly.
- Enlarge primary controls; move dense numeric channels and secondary settings into disclosure sections.
- Convert color control into a combined circular hue ring + inner SV field.

### Task 2: Selection Geometry
- Add rectangle selection geometry helpers and selection overlay.
- Make Select tool functional with drag-to-select, select-all, clear, and invert visual state.

### Task 3: Raster Transform
- Add transform geometry helpers.
- Move selected raster pixels by dragging; add flip horizontal/vertical and 90-degree rotation commands.
- Commit transform operations into document history.

### Task 4: Vector Layers
- Extend layer document with a vector layer kind and vector numbering.
- Store vector strokes as point/color/size/opacity data, not raster pixels.
- Add vector layer creation and rendering in compositing order.
- Add Vector Pen tool and selected-stroke editing (width, recolor, delete).

### Task 5: Contextual Properties + Integration
- Add a Properties panel that changes with Select / Transform / Vector tools.
- Wire keyboard shortcuts and toolbar states.
- Preserve left/right handed UI mirroring.

### Task 6: Verification + Preview
- Run full test suite and production build.
- Create tablet-safe static preview and PNG visual preview.
- Package project ZIP and update README/version.
