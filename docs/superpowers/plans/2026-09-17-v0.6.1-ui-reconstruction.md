# Drawing Studio V0.6.1 UI Reconstruction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the Drawing Studio workspace shell as a dense docked-palette desktop drawing UI while preserving all V0.6 engines and behavior.

**Architecture:** Add explicit PrimaryDock and SecondaryDock components around the existing Canvas. Existing functional panels are reused but reorganized into palette groups/tabs. CSS is rewritten around connected docks and compact palette headers rather than detached cards. Handedness is implemented through grid areas/classes so no engine coordinates change.

**Tech Stack:** TypeScript, DOM APIs, Canvas 2D, CSS, Node test runner.

**Spec:** `docs/superpowers/specs/2026-09-17-v0.6.1-ui-reconstruction-design.md`

## Global Constraints
- Preserve all 74 existing tests and V0.6 drawing behavior.
- Do not copy proprietary Clip Studio or MediBang icon assets.
- Standard mode exposes common drawing controls; Advanced only adds deeper controls.
- Right/left-handed mode mirrors UI chrome only, never canvas content.
- Permanent palette sections use 0–4px radii and connected dock separators rather than detached cards.
