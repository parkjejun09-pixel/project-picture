# V0.6.2 Core Tool Expansion Implementation Plan

**Goal:** Add the most visible missing illustration tools without changing the V0.6.1 workspace layout.

**Architecture:** Keep tool state in the editor reducer, keep drawing algorithms in focused `src/drawing/*` modules, and connect them to `DrawingCanvas` through tool-specific pointer flows. UI controls live in the existing Tool Strip / Properties / Fill palettes, with Reference as an independent dock palette.

**Deliverables:**
- Eyedropper samples the composited canvas and updates foreground color.
- Linear/radial Gradient renders to the active raster layer, constrained by the current selection bounds when present.
- Shape tool draws Line/Rectangle/Ellipse with stroke/fill controls.
- Magic Wand creates tolerance-based connected selections.
- Lasso creates polygon selections.
- Text foundation renders editable-settings text to raster on click.
- Reference palette imports/clears a local image and adjusts its preview opacity.
- Smart Fill adds Bucket / Enclose / Unpainted modes.
- Tool shortcuts and context Properties expose these workflows.
- Feature matrix and README are updated only after verification.

**Testing:** Unit-test pure color sampling, gradient math, polygon/magic-wand masks, shape geometry, text settings and advanced fill masks; markup tests cover tool/palette exposure; full existing suite must remain green.
